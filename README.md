A program that writes one sentence to `/output/entry.txt`: a pitch convincing a friend who has never coded to let an AI agent build their first app idea on make.fun. The sentence is fixed and deterministic — the same line on every run, no network, no input files. Built by an AI agent for make.fun's "A Day of One-Line Pitches" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

The pitch it writes:

> You don't need to learn to code — just describe the app idea you've been carrying around in plain words, and an AI agent on make.fun will build you a working first version you can actually tap and try.
